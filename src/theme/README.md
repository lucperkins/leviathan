# The annotated-text theme

Everything reusable in this directory: the machinery for a site that presents
a primary text with an editorial apparatus around it — numbered paragraphs,
hover tooltips for defined terms, quotations elsewhere on the site that link
back into the text and highlight themselves, footnotes, pull quotes,
marginalia, glossaries located in the text at build time, a sidebar of
collections with a mobile drawer, light/sepia/dark, and a remembered reading
position. Nothing in here is specific to any one book; everything
book-specific comes in through the contract below.

## The contract

A site adopts the theme by copying `src/theme/` and providing:

1. **`src/site.config.ts`** — the one module theme code imports from the
   site. It default-exports a `SiteConfig` (type in `src/theme/config.ts`):
   the site's title and subtitle, `storagePrefix` for localStorage keys, the
   shape of the primary text (`text.*`: collection, base path, what a unit is
   called, the work's name for quotation footers, its ordered divisions), the
   sidebar `sections`, the tooltip `refKinds`, the `apparatus` link list, the
   `essayCollections` that get the editorial treatment, and the sidebar
   `icons`.
2. **`src/styles/global.css`** — the site's stylesheet, imported by the
   theme's Layout. It must `@import "tailwindcss";` and
   `@import "../theme/styles/theme.css";`, then add site-specific styles.
3. **`src/components/Mark.astro`** — the site's mark (logo), a component
   taking `size` and `class`, rendered beside the masthead title.
4. **Content collections** under `src/content/<name>`, one directory per
   collection, assembled in `src/content.config.ts` from the schema pieces in
   `src/theme/content.ts` (`textUnitSchema`, `refEntrySchema`, `essaySchema`,
   `footnotesSchema`). The theme assumes content lives at
   `src/content/<collection>` — the collection name in the config is enough.
5. **`astro.config.ts` wiring** — the rehype plugins in `src/theme/plugins/`
   are factories; instantiate them with options built from the site config
   (see this repo's `astro.config.ts` for the full pipeline and ordering).
   `rehype-citations` additionally takes the site's own citation matcher and
   link builder (here: scriptural citations resolved to Wikisource).
6. **Pages** under `src/pages/` stay with the site (Astro requires it), but
   they are thin: a collection's entry page is `getStaticPaths` returning
   `entryRoutes(...)` (`src/theme/lib/routes.ts`) plus an `<EntryPage>`; a
   landing page is an `<IndexPage>`. Copy this repo's pages and adjust.
7. **`public/`** favicons: `favicon.svg`, `favicon-32.png`,
   `apple-touch-icon.png` — the Layout links all three.
8. **`src/alpine.ts`** re-exporting `src/theme/alpine.ts` (the entrypoint
   `@astrojs/alpinejs` and Storybook load).

## Layout of this directory

- `config.ts` — the `SiteConfig` type, i.e. the contract itself.
- `content.ts` — schema pieces for the collections.
- `layouts/Layout.astro` — the whole page shell: head, sidebar, drawer,
  pre-paint scripts for theme and accordion state.
- `components/` — everything the pages compose. Components take plain data as
  props (no `getCollection` inside them) so they render in Storybook; stories
  live with the consuming site (`src/components/*.stories.ts` here), since
  their fixtures are site data.
- `plugins/` — the rehype pipeline: term tooltips (`rehype-concepts`),
  paragraph numbering, quotation sourcing, pull quotes, unit-mention links,
  heading anchors, footnotes, marginalia, external-corpus citations, external
  links.
- `lib/` — pure machinery: text loading and quote locating (`text.mjs`),
  glossary indexing, mention counting, sorting, divisions, the
  definition-chain parser, prev/next helpers, route builders.
- `integrations/ref-watch.mjs` — dev-only; recompiles the text when a ref
  entry changes.
- `alpine.ts` — all client-side behaviour.
- `styles/theme.css` — the theme's CSS: tokens (`@theme`), the sepia ramp,
  and every component's styles. The palette is Tailwind's stock `stone`;
  sepia works by overriding the `--color-stone-*` ramp, so a site can retint
  everything the same way.

## Invariants the theme relies on

- The primary text's units are MDX with `number`, `title`, optional `part`
  (one of `text.divisions`), optional `numbered: false` for front matter.
- Quotations of the text elsewhere must be verbatim: location works by
  matching the first eight words against the files on disk.
- All interactivity is Alpine; markup generated by rehype binds with
  `x-data="name" x-bind="nameEvents"` so no `@`/`:` attribute names have to
  survive MDX.
- Storage keys are `<storagePrefix>:theme`, `<prefix>:reading`,
  `<prefix>:nav:<section>`, `<prefix>:nav-scroll`; changing the prefix logs
  every reader out of their saved state.

Nothing in `src/theme/` may name the consuming site's subject matter — for
this repo, `grep -ri "hobbes\|leviathan" src/theme --exclude=README.md`
should stay empty.
